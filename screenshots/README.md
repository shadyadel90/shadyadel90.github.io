# Project screenshots

Drop your app screenshots in this folder, then reference them from
`src/data/portfolio.ts` in the project's `screenshots` array:

```ts
screenshots: ["screenshots/taqa-ev-1.png", "screenshots/taqa-ev-2.png"],
```

Tips:

- Use iPhone-portrait images (any 9:19.5-ish ratio looks best — e.g. plain
  App Store screenshots, 1290 × 2796).
- PNG, JPG, and WebP all work. WebP keeps the site fast.
- Order in the array = order on the site.
